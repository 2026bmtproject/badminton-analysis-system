\begin{center}
\vspace*{1cm}
{\fontsize{16}{5}\selectfont\textbf{摘要}\par}
\end{center}

本專題開發一套羽球單打轉播影片的全自動分析系統，將一場完整的轉播影片轉換為逐拍資料。分析管線依序進行賽事影片分段、比分辨識、場地偵測、球員骨架追蹤、球體追蹤、擊球時刻偵測與球種分類，各階段以統一的資料契約串接，可單獨替換與重跑，單機一張消費級 GPU 即可執行。在管線之上，系統以大型語言模型生成賽評。另依觀眾歡呼為比賽片段排出精彩程度。使用者可在回看介面對照影片檢視所有結果。以 16 支公開的國際賽事轉播建立評估資料。在未參與開發的測試比賽上，影片分段 F1 為 98.66\%，擊球時刻偵測 F1 為 93.14\%。目前的主要瓶頸在於球種分類模型本身與擊球時刻的漏偵測，且系統尚無法察覺自身輸出的錯誤。
