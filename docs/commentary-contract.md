# Commentary contract v1 (migration PR A and runtime PR B)

This layer defines artifacts, internal schemas and deterministic runtime facts. Commentary is not yet a
runnable stage and is not registered in `modules/runner.py`.

## Production artifact

`stages/commentary/commentary.json` contains `{"rallies": [...]}`. Its StageSpec
record type is `modules.contracts.CommentaryRally`:

| Record | Fields |
| --- | --- |
| `CommentaryRally` | `segment_index`, `events`, `summary` (default `None`) |
| `StrokeCommentaryEvent` | `segment_index`, `stroke_index`, `frame`, `time_sec`, `text`, `source_fact_ids` |
| `RallyCommentarySummary` | `segment_index`, `text`, `source_fact_ids` |

These are Pydantic-validated dataclasses, compatible with the existing generic
artifact writer's `dataclasses.asdict` serialization. Constructor validation (or
`pydantic.TypeAdapter(CommentaryRally).validate_python(record)` when loading)
checks nested records. The generic reader still validates only the envelope;
plain dictionaries passed to the generic writer also bypass record validation.

- `segment_index` refers to the current upstream segments array.
- `stroke_index` is `StrokeLabel.event_index`, the **full-match** index into
  `events.json`; gaps are allowed and indices are never renumbered per rally.
- Python takes absolute `frame` from the source event and derives `time_sec`
  from source FPS. Generated text schemas exclude timing. The future assembler
  must verify returned indices and attach timing; schema validation alone cannot
  prove source correspondence.
- Events must be in ascending `(time_sec, frame, stroke_index)` order with
  nondecreasing frames. Invalid order is rejected, not silently corrected.
  Stroke indices are unique within a rally; nested segment indices must match.
- Summary is optional and untimed. There is no summary `start_sec`.
- Text and provenance IDs must be nonblank; `source_fact_ids` is required and
  nonempty for events and summaries. Checking that IDs exist in the supplied
  facts is a later runtime responsibility.
- Empty events are representable when no strokes can be mapped. In production,
  every ordinary mapped stroke with a label/confidence must produce an event,
  including low-confidence strokes. Highlight score must not gate those events.

## Direct dependency graph

| Relationship to commentary | Stages |
| --- | --- |
| Hard reads | `match_segmentation`, `event_detection`, `stroke_classification`, `score_recognition` |
| Optional context reads | `highlight_ranking`, `pose`, `court_detection`, `shuttle_tracking` |

Both kinds participate in ordering; only hard dependencies block readiness.
`audio_highlight` is not a direct read: it feeds `highlight_ranking`, which is
optional context only. Transitive dependencies of upstream stages are unchanged.

## Identity and internal domain

`modules.commentary.identity.CourtPositionToPlayer(top="a", bottom="b")` is
explicit caller input for a segment. Both identities are required and must
differ; the reversed mapping is equally valid. Mapping must be reconsidered on
side changes. There is no automatic inference or default. Unresolved players
remain `None` in internal facts and must not be guessed.

The reference repository's input wrappers are intentionally not migrated:
upstream `HitEvent` has only `frame`, while upstream `StrokeLabel` carries
`event_index`, court position (`top`/`bottom`), segment and classification.
Upstream `RallyScore` and its split-score fields retain their original contract.
Internal `RallyScore(a, b)` is the commentary fact representation, not a
replacement for that upstream record.

`schemas.py` contains rally/stroke analysis data and timing-free generated text
shapes. `facts/schemas.py` contains compact pose, court, shuttle and stroke facts;
missing optional vision facts can be `None`. `facts/tactical.py` contains candidate
and validated tactical evidence schemas. Their event indices are full-match
indices too. Tactical provenance checks enforce structural constraints; evidence
existence and interpretation still require later runtime validation.

The old draft `CommentaryLine` / `{"lines": [...]}` artifact is incompatible and
has no compatibility alias. Existing draft artifacts must be regenerated by the
future runtime. PR B adds only the deterministic adapters, builders and stroke
sequence analyzers described below.

## PR B runtime core

```python
from modules.commentary.adapters.upstream import read_commentary_inputs, build_rally_fact_from_stages
from modules.commentary.facts.builder import build_compact_rally_facts
from modules.commentary.identity import CourtPositionToPlayer
from modules.commentary.analysis.rally_analyzer import analyze_rally
from modules.commentary.analysis.stroke_event_analyzer import analyze_stroke_events

mapping = CourtPositionToPlayer(top="a", bottom="b")  # caller verifies this segment
inputs = read_commentary_inputs(match_path, segment_index, mapping)
fact = build_rally_fact_from_stages(stages=inputs, segment_index=segment_index,
                                  court_position_to_player=mapping)
compact = build_compact_rally_facts(stages=inputs, segment_index=segment_index,
                                  court_position_to_player=mapping)
analysis = analyze_rally(fact)
stroke_analyses = analyze_stroke_events(fact)
```

`UpstreamStageData` holds actual `modules.contracts` dataclasses; callers can
construct it from already-loaded records without filesystem access. It is an
in-memory input collection, not a new artifact format. Ordinary artifacts use
`modules.artifacts.read_artifact`, `PIPELINE` and `artifact_path`. The pose reader
alone streams records to avoid materializing a full-match ~156 MB skeleton file.
It validates the complete top-level JSON envelope, separators and trailing data,
including after the selected records, and retains only the selected segment.
Malformed/truncated JSON is an error, not an optional-data warning.

The adapter selects hit frames in the inclusive segment range and joins labels
by their original full-match array index. It rejects invalid or duplicate stroke
indices, frame/segment disagreement, missing required identity mapping and
invalid segment timing/FPS. Events sort by `(frame, event_index)` and retain their
original indices; absent labels remain unknown events. Python computes each
`time_sec = frame / fps`. RallyFact validates unique event indices, source-time
ordering, rally length, time containment and duration consistency with the
upstream 0.001-second quantization tolerance. It does not look up source frames.

Scores are segment-level **final score context**, never per-stroke scores.
The score artifact is required; a missing selected row gives nullable `a`, `b`,
`server` and `game_index`. Multiple recovered `sub_scores` fail explicitly:
the domain represents one rally per segment and has no sub-rally identifier.
Optional `highlight_ranking/highlights.json` supplies highlight context, including
valid `0.0`; missing artifact or row yields `None`. No audio artifact is read.

### Optional geometry and trust

Every selected event survives missing/unusable vision. Raw selected production
pose records remain in `inputs.vision.poses` for future work. Compact facts retain
source frame, absolute frame delta, confidence/quality and supported geometry.
Pose lookup uses the reference two-frame tolerance (earlier frame wins ties),
preferring usable keypoints within that window, then a usable bbox. Null or
unusable keypoints produce no pose geometry; a valid bbox can independently
support cautious court projection. A missing bbox is never replaced by zeroes.
There is no interpolation. Warnings identify unavailable event geometry.

`CourtCalibrationPolicy.STRICT` is the default: calibration must be confirmed
and usable. `ALLOW_UNCONFIRMED` permits projection but marks every resulting
court fact cautious with an explicit limitation. Neither policy bypasses
`detection_failed`, ambiguous calibration or invalid/singular homography.
Segment-specific calibration takes precedence over global calibration.
Homography maps court metres to image pixels and is inverted for projection;
invalid or out-of-court projections remove court facts only.

`modules.common.court_geometry` centralizes the detector's unchanged line model
and its 6.10 × 13.41 m dimensions. Normalization, zones, bounds and displacement
use those dimensions; the reference's 13.4 m approximation is removed. Thresholds
remain unchanged. Court facts describe observed hit locations and displacement
between observations, not continuous trajectories, running paths or forced movement.

The production `StrokeLabel` has no `shuttle_method` field: the adapter reads
that metadata from the **stroke_classification envelope**. A known method filters
shuttle observations exactly; an unknown method produces no directional fact
and a deterministic warning. Methods are never combined or guessed. Invisible,
missing/nonfinite coordinates and null/nonfinite/below-threshold confidence are
excluded from usable samples. Null confidence stays unknown in raw input and is
reported as a limitation, not converted to zero. Compact shuttle facts contain
image unit vectors, coarse image directions, window/sample counts and quality;
they contain no speed, 3D trajectory or landing-point claim.

### Analysis and provenance

Stable stroke IDs are `rally:{segment}:stroke:{full_match_event_index}`;
geometry appends `:pose`, `:court` or `:shuttle`. Source frames/windows are fields.
Rally pattern IDs append `:pattern:{name}` to the rally ID; local patterns use
`rally:{segment}:local:{first_index}-{last_index}:{name}`. Supporting IDs reference
retained stroke facts. IDs and ordering are deterministic for identical sources.

Confidence bands retain the reference thresholds: reliable ≥ 0.70, cautious
≥ 0.50, otherwise low (including unknown confidence). **Every** hit is retained
in both analyzers, including low confidence, missing labels and unknown players.
`AnalyzedStroke` therefore permits nullable identity/type/confidence, matching
RallyFactEvent. Derived patterns require reliable, identified supporting strokes;
pair/triple local patterns also require adjacent full-match indices and the
observed identity sequence. Low-confidence support never inherits the current
stroke's reliability. Local context is bounded to two–four previous hits.
`excluded_stroke_count` remains zero; legacy `should_speak` is always true and
`speaking_score` is only compatibility salience, never an inclusion gate.
Salience is heuristic priority, not correctness probability. Patterns describe
observed stroke sequences only, never winners, scoring causes, intent or causality.
